```
uv run epsilon                  # o: uv run python -m epsilon.main
```

Abrí `http://127.0.0.1:8765` en el navegador. Si activaste el bot, también podés hablarle por Telegram.

Para que arranque solo y quede en segundo plano, mirá [Servicio systemd](../servicio/).
