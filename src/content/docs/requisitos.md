- [uv](https://docs.astral.sh/uv/), para instalar las dependencias y correr el agente.
- Python 3.12 o superior.
- Una `GEMINI_API_KEY` para resúmenes, imagen a CSV e IA.

> **La clave es opcional.** Sin ella, las notas, los archivos, la búsqueda y la memoria siguen funcionando.
